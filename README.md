# CSUN Map Guessing Game

A location-based Google Maps game created for COMP 484 using HTML, CSS, JavaScript, and the Google Maps JavaScript API.

## Description

This project challenges users to identify important CSUN campus locations by double clicking on the correct area of the map. The game tracks score, completion time, and best completion time using Local Storage.

## Features

- Interactive Google Maps integration
- Double-click location guessing
- Correct and incorrect answer feedback
- Green/red highlighted answer areas
- Score tracking system
- Game timer
- Persistent high score using Local Storage
- Five campus locations
- Disabled map zooming and panning
- Restart game functionality

## Technologies Used

- HTML5
- CSS3
- JavaScript
- Google Maps JavaScript API
